<div align="center">
    <h1>rig</h1>
</div>

<p align="center">
    <i>Manage multiple profiles for each agent harnesses.</i>
</p>

`rig` is a Python utility that helps you isolate different profiles of your agent
harness. This utility is originally created to separate personal and work
profiles, as these have different allowed MCPs, tools, and skills, and security
and privacy requirements.

> [!note]
> Supports the following agent harnesses:
>
> - Google Antigravity CLI
> - Anthropic Claude Code CLI
